# Замеры производительности (DoD-6, NFR-PERF, SPEC 15 §7)

Скрипт: `npm run bench -- --url <base> [--write] [--tg] [--chat 20]` (`domus/scripts/bench.js`). Таблицу ниже скрипт печатает сам; строки «вручную» — по методике 15 §7.

## Прогон 1 — локально, 28.10.2026

- **Где:** ноутбук автора, Windows 11 Pro, Node 26.5, локальный сервер (`node server.js`), база PGlite (`.pglite/`), модель — Gemini по ключу из `.env` (настоящие вызовы).
- **Сеть:** localhost. Поэтому PERF-05/06 здесь показывают время приложения без сети и холодного старта Vercel — на продакшене цифры будут выше (см. «Не измерено»).
- **Команда:** `npm run bench -- --url http://localhost:3001 --write --tg --chat 20`. Флаг `--write` создаёт одно удержание в локальной базе и сразу его снимает.
- **Прогон 2 (тот же день):** локальная учётка руководителя `bench`, `BENCH_LOGIN=bench BENCH_PASSWORD=… npm run bench -- --url http://localhost:3001 --write --chat 0` — строки summary и PERF-07.

**Наблюдения.**
- Первый текст почти всегда приходит одновременно с `done`: ответ агента отдаётся одним-двумя кусками в конце, а не по словам. PERF-03 выполняется за счёт статуса «Думаю… / Подбираю квартиры…». Медленные ответы (6–9 с, хвост p95) — вопросы с вызовом инструментов (подбор, расчёт рассрочки).
- Вопрос «Сколько стоит депозит за бронь?» (ручная проверка потока) ушёл агенту `apt_finder` и получил подборку квартир — маршрутизация для D6 (eval агентов).

## Прогон 3 — продакшен, 28.10.2026

`npm run bench -- --url https://domus-askar.vercel.app --tg --chat 20` с ноутбука автора (Ташкент → Vercel fra1 / Neon eu-central-1), без `--write`.

| NFR | Что | Цель | Значение | ✓ | Примечание |
|---|---|---|---|---|---|
| — | Холодный старт (первый запрос) | — | 868 мс | — | не входит в медианы |
| PERF-06 | GET /api/apartments/status | p95 < 300 мс | p50 362 мс · p95 383 мс | ✗ | сеть: TCP connect 0,15–0,26 с |
| PERF-06 | GET /api/buildings/chinor-park | p95 < 300 мс | p50 763 мс · p95 843 мс | ✗ | ответ 588 КБ |
| PERF-05 | Ответ вебхуку Telegram | p95 < 500 мс | — | — | локальный TELEGRAM_WEBHOOK_SECRET не совпадает с боевым |
| PERF-03 | Первое видимое событие чата | медиана < 2 с | 0,39 с | — | ИИ на проде выключен — строка не в счёт |
| PERF-04 | Полный ответ чата | медиана < 8 с | 0,46 с | — | то же: ответы по сценарию без модели |

**Наблюдения.**
- PERF-06 на проде упирается в сеть, а не в сервер: статическая `favicon` отдаётся за 0,83 с до первого байта, одно TCP-соединение — 0,15–0,26 с. Локально те же запросы — p95 23–39 мс. Для защиты: замер из Европы или по `Server-Timing`.
- В Vercel Production нет `GEMINI_API_KEY` / `ANTHROPIC_API_KEY` → чат отвечает сценариями, health показывал ai off. Нужно: добавить ключ в Settings → Environment Variables (Production) → Redeploy, затем повторить `--chat 20`.
- Telegram на проде настроен (все `TELEGRAM_*` есть); надпись `not_configured` в health была неверной — исправлено на `ok`.
